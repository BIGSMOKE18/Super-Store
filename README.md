# 🏬 Super Store Sales Analysis & Forecasting Dashboard

## 📊 Overview

This project presents a **comprehensive data analysis and interactive dashboard** for the **Super Store Sales Dataset**, designed to uncover key business insights and forecast future sales trends.  

The goal of this project is to **analyze sales performance**, **identify profit-driving factors**, and **predict short-term sales** using data analytics and visualization tools. The project transforms raw transactional data into actionable insights through **data cleaning, EDA, and forecasting models** — visualized in a modern and intuitive **Power BI dashboard**.

---

## 🧠 Objectives

- Perform **Exploratory Data Analysis (EDA)** on Super Store sales data.  
- Build **interactive dashboards** to visualize key metrics like sales, profit, region, and category performance.  
- Identify **top-performing regions, categories, and customer segments**.  
- Analyze the **impact of discounts, shipping mode, and payment type** on profit margins.  
- Create a **15-day sales forecast** to help in short-term business planning.

---

## 🧾 Dataset Description

The dataset includes transactional data from a retail Super Store with fields like:
| Feature | Description |
|----------|--------------|
| **Order ID** | Unique identifier for each order |
| **Order Date / Ship Date** | Order and shipment timeline |
| **Sales** | Monetary value of items sold |
| **Quantity** | Units sold |
| **Discount** | Discount applied to each order |
| **Profit** | Profit earned per transaction |
| **Category / Sub-Category** | Product classification |
| **Region / State** | Customer location |
| **Segment** | Customer type (Consumer, Corporate, Home Office) |
| **Ship Mode** | Delivery mode (Standard, Second Class, etc.) |

## 📈 Dashboard Overview

The dashboard is divided into **two main views**:

### 🟦 1. Super Store Sales Dashboard
An interactive overview of sales performance across categories, regions, and customer segments.

#### Key Insights:
- **Total Sales:** 1.6M  
- **Total Orders:** 22K  
- **Total Profit:** 175K  
- **Average Ship Days:** 4  
- **Top-Performing Region:** West (33%)  
- **Most Profitable Category:** Office Supplies  

#### Visuals Included:
- **Sales by Segment, Region, and Payment Mode**
- **Sales and Profit by Month**
- **Sales by Ship Mode**
- **Sales by Category & Sub-Category**
- **Geographical Sales & Profit by State**

### 🟨 2. Sales Forecast – 15 Days Prediction
A time-series forecasting dashboard to predict short-term sales using historical data trends.

#### Features:
- **15-Day Forecast Visualization**
- **Sales by State Breakdown**
- **Historical Trend (2019–2020)**
- **Interactive Date Range Selection**

#### Key Insights:
- Forecast predicts a steady **upward trend** in early January.
- **California, New York, and Texas** are top-performing states.
- Short-term demand spikes during **Q4 (Oct–Dec)** months.

## 🔍 Key Findings

- The **West region** consistently leads in both sales and profit.  
- **Consumer segment** contributes the highest share (48%) of total sales.  
- **Standard shipping mode** dominates with 0.33M sales.  
- **Technology and Office Supplies** categories generate maximum profit.  
- Short-term sales forecast indicates **growth stability** with minor seasonal fluctuations.
